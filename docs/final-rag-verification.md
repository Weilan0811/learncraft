# 最终检索方案实施与本地验收

日期：2026-11-20。

## 实现

- 检索片段使用文档、章节位置及片段序号生成唯一编号；正文缓存继续采用原有数据库身份。
- 索引先在独立目录构建并核验，再替换，保留旧目录备份。
- 大纲统一校验引用、章节数量和非空查询；错误最多修复一次。资料不足保持失败；校验通过后才发布`outline_ready`。
- 查询规划、大纲生成与修复、并发章节的实际模型用量随任务产物保存，包括缓存和思考用量字段。
- 检索记录保留逐查询资料、最终提供正文、展示范围、位置和索引信息；BGE模型在同进程中复用。
- 互动课程大纲提示遵守请求的章节上限，去除固定4—8章与请求参数之间的冲突。

## 解释范围

编号修复改变了少量排序和合并结果，尚未重做整套生成质量评分。历史成绩继续绑定旧快照，不能将位置变化解释成质量提升。大纲引用编号合法也不代表每个知识主张都已由人工确认。

用量依据以任务产物中的`model_calls`及修复记录为准；现有模型服务可能进行结构修复或网络重试，一次逻辑步骤不保证只有一次HTTP请求。没有返回用量的请求按服务商账单核对。
