# 演示脚本

目标：用 3–4 分钟展示“三种主打内容 + 一次完整学习闭环”。以下步骤与真实任务一致，可直接照录。

## 准备

1. 后端与前端启动（见 README 快速开始）。
2. 打开 `http://localhost:5173`，确认右上角服务状态为“服务正常”。
3. 浏览器窗口建议 1440×900，隐藏书签栏。
4. 录屏软件录制浏览器区域，保留鼠标指针。

## 镜头一：互动讲义（约 90 秒）

1. 主题输入：`提示工程中的少样本示例`。
2. 类型选择：互动讲义。
3. 要求输入：`面向零基础学员，用 4 个章节讲解什么是少样本示例、为什么有效、如何挑选示例、常见误区。每节包含一段讲解、一个选择题或反思题。`
4. 点击生成，镜头停留在进度区：展示“检索 → 规划 → 逐单元完成 → 校验 → 完成”。
5. 生成完成后滚动预览：展示章节导航、讲解、单选/短答互动。
6. 答一道选择题（故意选错或选对均可），展示反馈。
7. 滚到底部：学习摘要出现，镜头依次划过完成度、正确率、薄弱概念、建议复习章节。

参考任务：`task_50d8ee6ad2ac`。

## 镜头二：针对薄弱点再生成（约 45 秒）

1. 点击“针对薄弱点再生成”。
2. 镜头展示主题被替换为复习主题、补充提示进入请求。
3. 等待新任务完成，展示复习课章节顺序：原薄弱章节被排到第一节。

参考任务：`task_8ec63395261c`。

## 镜头三：播客（约 30 秒）

1. 历史记录打开 `task_ba2caf388555`《向量检索入门》。
2. 展示多人对谈脚本与角色标注。
3. 打开导出音频，播放 10 秒。

## 镜头四：图文推文（约 20 秒）

1. 历史记录打开 `task_2c54ad48fce1`《AI Agent 工作流的设计与实践》。
2. 快速滚动封面、章节配图与长文排版。

## 镜头五：可靠性（约 20 秒，可选）

1. 打开任意存在失败资源的任务。
2. 展示失败资源列表与“重试”按钮。
3. 点击重试，展示状态从失败变为生成中/成功。

## 收尾字幕

> 输入一个主题，产出可以直接学、直接发、直接听的教学内容。
> 互动讲义支持答题、摘要与针对薄弱点再生成。

## 录制与压缩

- 推荐 1080p、30fps，输出 GIF 控制在 8–12 秒、宽度 760px，放在 `docs/assets/demo-generation.gif`。
- 完整版视频可放在 `docs/assets/demo-full.mp4`，README 只嵌 GIF。
- GIF 建议只截取“生成进度 → 答题 → 摘要出现 → 点击再生成”这一段。

## 复现检查

- [ ] 生成过程中章节逐个出现，而不是最后一次性出现。
- [ ] 答题后摘要数字变化。
- [ ] “针对薄弱点再生成”只在互动讲义预览出现。
- [ ] 复习课主题包含薄弱概念。
