讲解区 · LLM 自由生成

先把问题拆成“线索”

当用户提出一个问题时，模型并不会像人一样“真正读懂心意”，它会从输入文本中提取语义线索： 主题是什么、任务是什么、约束是什么、期望输出是什么。

对交互式课件来说，讲解部分可以允许大模型自由设计版面；但交互控件要由模板生成， 这样按钮、输入框、事件提交和反馈才能稳定运行。

设计边界

LLM 负责“讲清楚、讲好看”；模板负责“点得动、记得住、传得出去”。
