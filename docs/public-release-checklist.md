# 公开发布前检查

此分支准备公开候选，现有开发仓库继续保持私有。PR 合并、创建公开可见的远端及可见性切换由所有者确认。

## 发布内容

- 保留内容生成、学习记录及自建知识库能力。
- 使用自行编写的示例材料；外部语料、实验题目、标注、详细报告和生成数据留在私有归档。
- 公开候选从经过清理的开发历史产生，不复制私有开发仓库的 PR、评论、附件和实验备份分支。

## 发布核对

- [ ] 所有者及合作者确认项目根许可证，保留第三方原有许可。
- [ ] 合作者核对作者名称、作者邮箱与账号关联。
- [ ] 确认现有插图、示例和测试媒体可以公开。
- [ ] 检查当前文件及全部保留历史中的凭据、语料、数据库及实验资料。
- [ ] 干净环境的安装、启动、示例建库、检索与文档增删验证通过。
- [ ] 本地私有归档能够恢复。
- [ ] 所有者检查候选代码及验证报告后，再批准远端发布。

历史清理和文件检查的实际结果存入仓库外的私有交付记录，避免再次将本地材料名称和机器路径写入公开文档。
