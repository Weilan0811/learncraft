这里需要注意的是，虽然 mcp 是为了 ai 而定制出来的标准，但实际上 mcp 本身却和 ai 模型没有关系。
它并不关心 agent 用的是哪个模型，mcp 只负责帮 agent 管理工具、资源和提示词。

我听说女朋友肚子疼，于是问 ai agent 或者说 mcp client 我女朋友肚子疼应该怎么办？

web browser 访问指定的网站之后，将内容返还给 agent，agent 再转发给 ai 模型。
